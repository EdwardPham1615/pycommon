# Code of Conduct

## The short version

Be respectful. Assume the other person is acting in good faith. Critique code,
not people.

## Expected behaviour

- Give feedback on the work: what is wrong, why it matters, and what would be
  better. "This drops the request ID on error paths" is useful; "this is sloppy"
  is not.
- Accept that a reviewer may disagree with a decision you have already made, and
  that a maintainer may decline a change that is good work but wrong for this
  library.
- Assume ignorance before malice. Most surprising code has a reason behind it
  that is not in the diff.

## Unacceptable behaviour

Harassment, personal attacks, discriminatory language, deliberate
intimidation, publishing others' private information, and sustained disruption
of discussions.

## Scope

This applies in the issue tracker, pull requests, discussions, and anywhere
someone is representing the project.

## Enforcement

Report concerns to the maintainer privately at the email on their GitHub
profile. Reports are handled confidentially. The maintainer may edit or remove
contributions, and may block accounts, when behaviour falls outside these
expectations.

Enforcement is a judgement call made by one person, so it will not be perfect.
If you think a decision was wrong, say so — privately is fine.
